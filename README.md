# Sarvam AI Widget

A native macOS menu-bar widget built with [Native SDK](https://native-sdk.dev/).

## Supported features

- Translate to Hindi, Tamil, Telugu, or English

## Downloads

Install the latest build of Sarvam AI Widget from the
[Releases page](https://github.com/akadotsh/sarvam-ai-widget/releases).

- macOS: available
- Windows: coming soon
- Linux: coming soon

Development releases are ad-hoc signed. Before a public launch, configure an
Apple Developer ID signature and notarization.
