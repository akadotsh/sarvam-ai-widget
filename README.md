# Sarvam Translate

A native macOS menu-bar widget built with [Native SDK](https://native-sdk.dev/)
that translates text with Sarvam AI.

The widget supports Hindi, Tamil, Telugu, and English targets, Sarvam's four
Mayura tones, and native or international numeral formats.
